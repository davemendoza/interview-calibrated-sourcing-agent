# data/ (local only)

Everything in this folder except this file is ignored by git. Keep real people here, never in the repo.

| File | What it is | Made by |
|---|---|---|
| `evidence.jsonl` | Raw evidence from every harvester | `icsa harvest` |
| `test_set.xlsx` or `test_set.csv` | People you have already tiered (Name, Your tier, Test challenge) | You |
| `outcomes.csv` | Post-interview results (name, stage, result, passed_signals, failed_signals) | You, after each interview round |
| `calibration.json` | Signal weights learned from outcomes | `icsa recalibrate` |
